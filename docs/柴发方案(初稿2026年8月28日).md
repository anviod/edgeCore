# B单位柴油发电机、UPS及供配电远程监控与控制系统技术方案

## 1. 项目概述

### 1.1 项目背景

本项目面向 B 单位供配电系统建设远程监测、远程控制、自动切换及故障告警系统。

系统以 B 单位现有市电、柴油发电机、UPS、低压配电设备及机房环境监测设备为基础，在 A 单位配置综合管控一体机，通过现有光缆建立 A、B 两单位之间的远程通信链路，实现：

* B 单位市电运行状态监测；
* 市电失电、缺相、欠压监测；
* 主用、备用柴油发电机运行状态监测；
* 主用、备用柴油发电机远程启停；
* 主用柴油发电机启动失败后的备用机组联动；
* 发电机输出与市电之间的自动切换；
* 发电机供电状态下负荷向 UPS 的切换；
* UPS 运行状态及电池状态监测；
* 配电柜主要电气参数监测；
* 发电机房温度、湿度、烟感等环境参数监测；
* 故障声音报警；
* 通信链路中断报警；
* 告警记录、事件记录及历史数据查询；
* 用户权限管理；
* 摄像机、PLC、HMI、发电机控制器及传感器联动。

本方案采用 `edgeCore` 作为 B 单位现场边缘控制及数据采集核心，在 A 单位部署综合管控一体机，实现现场设备与远程监控系统之间的数据汇聚、状态判断、联动控制和历史数据管理。

# 2. 建设目标

系统建设目标如下：

1. 建立 B 单位供配电设备统一监测体系。
2. 实现市电异常情况下的自动供电切换。
3. 实现主、备用柴油发电机组的自动启停联动。
4. 实现柴油发电机运行状态远程监视。
5. 实现 A 单位对 B 单位关键设备的远程控制。
6. 建立 UPS、配电、电能质量及环境参数监测体系。
7. 建立 A-B 两地通信链路状态监测机制。
8. 建立完整的告警、事件及历史数据管理体系。
9. 实现 PLC、发电机控制器、HMI、摄像机及传感器统一接入。
10. 保留现场控制系统的独立运行能力，远程监控系统故障不得影响现场保护及基本自动控制。


# 7. ATS双电源自动切换系统

## 7.1 ATS功能

ATS负责：

* 市电输入；
* 发电机输入；
* 电源状态检测；
* 市电/发电机自动切换；
* 电气机械联锁；
* 分合闸状态反馈；
* 故障状态反馈。

推荐采用四极或符合现场接地系统要求的双电源切换设备，具体极数根据现场供电系统及接地形式最终确定。

## 7.2 ATS控制原则

ATS应采用**硬件自动控制为主、远程系统监视为辅**的设计原则。

正常情况下：

```text
市电正常
    ↓
ATS选择市电
    ↓
负载由市电供电
```

市电异常：

```text
市电异常
    ↓
发电机启动
    ↓
发电机电压/频率正常
    ↓
ATS切换至发电机
    ↓
负载由发电机供电
```

市电恢复：

```text
市电恢复
    ↓
市电稳定确认
    ↓
ATS切回市电
    ↓
负载恢复市电供电
    ↓
发电机进入冷却运行
    ↓
发电机停止
```

```text
    │       ▼
    │   频率正常

    │       ▼

    │       ▼
```

# 10. 主用发电机故障切换备用发电机

当主用柴油发电机启动失败时：

```text
市电异常
   ↓
主用发电机启动
   ↓
启动失败
   ↓
产生“主用发电机启动失败”事件
   ↓
上送A单位
   ↓
启动备用发电机
   ↓
备用发电机运行稳定
   ↓
ATS切换至备用发电机
   ↓
备用发电机供电
```

其中：

**“启动失败”必须由发电机控制器实际反馈或启动超时逻辑确认，不允许仅根据通信中断判定为启动失败。**

通信中断应单独作为：

> 发电机通信异常

进行处理。

# 14. 发电机与UPS联动

根据用户提出的“发电机供电时自动切换至 UPS、恢复市电后切换至市电输出”的要求，系统设计为：

```text
                ┌──── 市电 ─────┐
                │               │
                ▼               │
              ATS               │
                │               │
                ▼               │
             UPS输入            │
                │               │
                ▼               │
               UPS              │
                │               │
                ▼               │
             UPS输出             │
                │               │
                ▼               │
              负荷 ◄─────────────┘
```

这里建议在工程实施时明确：

> UPS的输入电源可以由 ATS 在市电与发电机之间自动切换，而 UPS 输出始终保持连续供电。

因此并不是通过“频繁切换 UPS 输出侧电源”实现，而是通过：

**ATS切换 UPS 输入源 + UPS持续向重要负荷供电**

实现无间断供电。

# 26. 边缘联动逻辑

edgeCore负责执行非保护性的边缘联动逻辑。

例如：

```text
IF 市电 = 异常
AND 自动模式 = TRUE
THEN
    启动主用发电机
```

主机启动失败：

```text
IF 主用发电机 = 启动失败
AND 备用发电机 = 可用
THEN
    启动备用发电机
```

发电机稳定：

```text
IF 发电机运行 = TRUE
AND 电压正常 = TRUE
AND 频率正常 = TRUE
AND 稳定时间 >= T
THEN
    允许ATS切换
```

市电恢复：

```text
IF 市电 = 正常
AND 连续稳定时间 >= T
THEN
    ATS切回市电
```

```text
  ├── 本地告警继续
```

# 53. 方案核心特点

本方案最终形成的不是单独的“发电机监控系统”，而是一套完整的：

> **市电 + ATS + 柴油发电机 + UPS + 配电 + PLC + 环境 + 视频 + edgeCore + 远程综合管控系统**

其中：

**强电系统负责供电和保护；**

**ATS负责电源切换；**

**发电机控制器负责机组自身控制；**

**PLC负责现场联锁及控制接口；**

**UPS负责重要负荷不间断供电；**

**edgeCore负责现场数据采集、状态管理、边缘联动和远程控制接口；**

**A单位综合管控一体机负责统一监视、告警、历史数据、权限和远程操作。**

整个系统按照“**保护不依赖软件、自动控制不依赖远程通信、远程系统不介入电气保护**”的原则设计，使现场供配电系统、自动控制系统和远程监控系统保持清晰的功能边界。

如果作为正式招标/设计文件，下一步建议直接在这份基础上继续细化成 **《一次系统图 + 二次控制逻辑 + PLC I/O点表 + edgeCore点表 + 通信拓扑 + 设备清单/BOM + 控制时序图》**，这样就可以从“方案说明”进一步落到施工和软件实施层面。
