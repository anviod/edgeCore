## 两条核心铁律

| # | 铁律 | 最小判据 |
|---|------|---------|
| 1 | **任何性能优化不得以牺牲稳定性为代价** | 不得移除或弱化保留防线；不得新增无超时、无退避、无 recover 边界的 IO / 调度路径；性能类变更须附故障注入复跑结论 |
| 2 | **任何架构优化不得增加系统恢复复杂度** | 恢复的人工介入度、外部依赖、步骤数不增加；判定口径为「恢复复杂度净退化」——增强自愈不判违规 |

**工业现场资源保护总纲**：不得把频繁重连当作默认自愈方式。恢复优先级——优先复用现有连接 → 优先恢复单个设备的采集 → 仅在满足严格准入条件时重建共享链路 → 任何情况下不得以反复拨号掩盖资源释放失败。

## 规范用语

| 用语 | 含义 |
|------|------|
| **必须** | 不满足则违反工程规则或阻断发布 |
| **禁止** | 不允许出现的行为 |
| **应当** | 默认必须遵循；例外需给出理由并留痕 |
| **建议** | 推荐实践，不直接作为阻断条件 |

规则编号稳定，不因章节调整变化——代码评审、故障单与发布记录直接引用编号（如 REC-002、CONN-001），不依赖描述性文字。
